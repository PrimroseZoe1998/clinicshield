# Security reporting

## Report a suspected vulnerability privately

Email [zmangwendeza@gmail.com](mailto:zmangwendeza@gmail.com) with a subject such as
ClinicShield security report. This is the maintainer contact selected for private
security reports. Do not disclose a suspected vulnerability in a public issue.

Please include the affected version or commit, a short description, steps to
reproduce using fictional data, the expected and observed result, and the possible
impact. If you can, suggest a fix. Do not send patient information, passwords,
access tokens, private inventories or unredacted logs. Ask first if sensitive
material is needed to explain the issue; agree a suitable private way to share it.

The maintainer can use the email thread to ask questions and coordinate a fix and
disclosure. No response deadline or guaranteed remediation time is promised here.
The address is documented with the owner's permission; mail delivery has not
been independently tested by the app or by an automated message.

## Prototype scope

ClinicShield is a prototype, not a production security or compliance certification.
Use the current documented checkpoint and review its known limitations. There
is no long-term support guarantee or declared supported-release window yet.
Do not upload patient data. Report handling does not authorize scanning networks
or accessing systems without the owner's permission.
